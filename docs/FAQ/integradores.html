Preguntas Frecuentes para Integradores

Respuestas a las consultas más comunes durante el proceso de integración con Lakaut AC.

Primeros Pasos​

¿Cómo obtengo mis credenciales de integrador?​

Contactá a Lakaut AC para solicitar tus credenciales. Te proporcionaremos:

  • integratorId: Tu identificador único de integrador
  • Acceso al ambiente de pruebas
  • Documentación técnica específica

¿Necesito registrar mi dominio?​

Sí. Por seguridad, tu dominio debe estar en nuestra lista de orígenes autorizados. Envianos:

  • Dominio completo (ej: https://miapp.com)
  • Subdominios si corresponde (ej: https://app.miapp.com)

¿Existe un ambiente de pruebas?​

Sí. Tenemos un ambiente de sandbox que te permite:

  • Probar la integración sin consumir créditos
  • Usar certificados de prueba
  • Simular diferentes escenarios

Solicitá acceso al ambiente de pruebas al iniciar tu integración.

Integración con iframe​

¿Mi sitio debe usar HTTPS?​

Sí, es obligatorio. El iframe de firma solo funciona sobre HTTPS por razones de seguridad.

¿Qué permisos necesita el iframe?​

El iframe requiere los siguientes permisos:

allow="clipboard-read; clipboard-write"

Estos permisos son necesarios para funcionalidades específicas del proceso de firma.

¿Puedo personalizar la apariencia del iframe?​

El contenido interno del iframe no es personalizable (mantiene la identidad de Lakaut AC). Sin embargo, podés:

  • Controlar el tamaño del iframe
  • Decidir si mostrarlo en modal o embebido
  • Aplicar estilos al contenedor del iframe

¿Cómo valido que los mensajes vienen del iframe de Lakaut?​

Siempre validá el origen del mensaje:

window.addEventListener('message', (event) => {
  if (event.origin !== 'https://www.lakautac.com.ar') return;
  // Procesar mensaje
});

Nunca proceses mensajes sin validar el origen.

¿Qué pasa si el usuario recarga la página durante el proceso?​

El estado del proceso de firma se pierde. El usuario deberá iniciar el proceso nuevamente. Recomendamos:

  • Mostrar advertencias antes de recargar
  • Guardar el estado de tu aplicación de forma independiente

Manejo de Documentos​

¿Qué formato de documento debo enviar?​

El documento debe ser:

  • Formato: PDF
  • Codificación: Base64 (sin prefijo data:application/pdf;base64,)
  • Tamaño máximo: 10MB

¿Cómo convierto un archivo a Base64?​

Ejemplo en JavaScript:

function fileToBase64(file) {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = () => {
      // Remover el prefijo data:...;base64,
      const base64 = reader.result.split(',')[1];
      resolve(base64);
    };
    reader.onerror = reject;
    reader.readAsDataURL(file);
  });
}

¿Puedo enviar el documento desde mi backend?​

Sí. Podés:

  1. Generar el PDF en tu backend
  2. Convertirlo a Base64
  3. Enviarlo a tu frontend
  4. Tu frontend lo pasa al iframe mediante lakaut.load.file

¿Cómo verifico la integridad del documento firmado?​

El evento lakaut.signature.completed incluye el hash SHA-256 del documento:

{
  document: {
    sha256: "abc123...",
    size: 123456,
    mime: "application/pdf"
  }
}

Guardá este hash para verificaciones futuras.

Datos del Usuario​

¿Qué datos del usuario necesito enviar?​

En el mensaje lakaut.init debés incluir:

userData: {
  cuil: '20-12345678-9',  // Formato XX-XXXXXXXX-X
  email: 'usuario@ejemplo.com',
  gender: 'M'  // 'M' o 'F'
}

¿Cómo valido el formato del CUIL?​

El CUIL debe tener formato XX-XXXXXXXX-X (con guiones). Ejemplo de validación:

function validarCUIL(cuil) {
  const regex = /^\d{2}-\d{8}-\d$/;
  return regex.test(cuil);
}

¿Qué pasa si envío datos incorrectos?​

El iframe validará los datos y responderá con un evento lakaut.error indicando el problema específico.

Errores Comunes​

Error: "Dominio no autorizado"​

Causa: Tu dominio no está en la lista de orígenes permitidos.

Solución: Contactá a Lakaut para registrar tu dominio.

Error: "Invalid integratorId"​

Causa: El integratorId es incorrecto o no existe.

Solución: Verificá que estés usando el integratorId correcto proporcionado por Lakaut.

Error: "Document too large"​

Causa: El documento supera el límite de 10MB.

Solución: Optimizá el PDF (reducir imágenes, comprimir) o contactá a Lakaut si necesitás un límite mayor.

No recibo el evento lakaut.handshake.ack​

Causas posibles:

  1. Enviaste lakaut.init antes de que el iframe cargue
  2. El origen en postMessage es incorrecto
  3. El integratorId es inválido

Solución:

iframe.onload = () => {
  // Enviar DESPUÉS del onload
  iframe.contentWindow.postMessage({
    type: 'lakaut.init',
    payload: { /* ... */ }
  }, 'https://www.lakautac.com.ar'); // Origen exacto
};

El documento no se carga automáticamente​

Causa: Enviaste lakaut.load.file antes de recibir lakaut.handshake.ack.

Solución: Esperá el handshake:

window.addEventListener('message', (event) => {
  if (event.data.type === 'lakaut.handshake.ack') {
    // AHORA podés cargar el documento
    iframe.contentWindow.postMessage({
      type: 'lakaut.load.file',
      payload: { /* ... */ }
    }, 'https://www.lakautac.com.ar');
  }
});

Seguridad​

¿Cómo protejo los datos sensibles?​

Mejores prácticas:

  • Nunca expongas tu integratorId en código público
  • Validá siempre el origen de los mensajes
  • Usa HTTPS en toda tu aplicación
  • No almacenes documentos sin cifrar

¿Qué es el nonce y por qué es importante?​

El nonce es un identificador único para cada sesión de firma. Debe ser:

  • Único para cada inicialización
  • Generado de forma segura: crypto.randomUUID()
  • Usado para prevenir ataques de replay

¿Qué es el idemKey?​

El idemKey (clave de idempotencia) previene firmas duplicadas. Si enviás dos requests con el mismo idemKey, solo se procesará uno.

Generalo así:

idemKey: crypto.randomUUID()

Performance​

¿Cuánto tarda en cargar el iframe?​

Típicamente 1-3 segundos, dependiendo de:

  • Conexión del usuario
  • Carga del servidor
  • Caché del navegador

¿Puedo precargar el iframe?​

Sí, podés cargar el iframe de forma anticipada (antes de que el usuario lo necesite) para mejorar la experiencia. El iframe permanecerá en estado de espera hasta que envíes lakaut.init.

¿Hay límite de firmas por minuto?​

Existen rate limits para prevenir abuso. Si necesitás límites mayores para tu caso de uso, contactanos.

Facturación y Créditos​

¿Cómo funciona el sistema de créditos?​

Cada firma consume créditos de tu cuenta. El consumo ocurre cuando:

  • El usuario completa exitosamente una firma
  • No se cobran créditos por firmas canceladas o fallidas

¿Qué pasa si me quedo sin créditos?​

El iframe mostrará un error 402 (Saldo Insuficiente). El usuario no podrá firmar hasta que recargues créditos.

¿Puedo consultar mi saldo de créditos?​

Sí, mediante la API de administración. Contactá a Lakaut para obtener acceso.

Testing​

¿Cómo pruebo sin consumir créditos?​

Usá el ambiente de sandbox que te proporcionamos. Incluye:

  • Certificados de prueba
  • Créditos ilimitados
  • Todos los flujos disponibles

¿Puedo automatizar tests de integración?​

Sí, pero con limitaciones. El iframe requiere interacción del usuario (autenticación, selección de certificado). Podés automatizar:

  • Carga del iframe
  • Envío de mensajes
  • Validación de respuestas

No podés automatizar la firma en sí (requiere certificado real del usuario).

¿Cómo simulo diferentes escenarios de error?​

En el ambiente de sandbox podés simular:

  • Certificados expirados
  • Documentos inválidos
  • Errores de red
  • Timeouts

Consultá la documentación del sandbox para detalles.

Soporte Técnico​

¿Cómo reporto un problema?​

Enviá un email a soporte@lakaut.com incluyendo:

  • Tu integratorId
  • Descripción del problema
  • Pasos para reproducir
  • Logs de consola del navegador
  • Capturas de pantalla si aplica

¿Cuál es el tiempo de respuesta del soporte?​

  • Ambiente de producción: 24-48 horas hábiles
  • Problemas críticos: Respuesta prioritaria
  • Consultas generales: 2-5 días hábiles

¿Tienen documentación de la API completa?​

Sí, consultá la sección API Reference de esta documentación.

Migración y Actualizaciones​

¿Cómo me entero de cambios en la API?​

Te notificaremos por email sobre:

  • Nuevas funcionalidades
  • Breaking changes (con anticipación)
  • Deprecaciones
  • Mantenimientos programados

¿Hay versionado de la API?​

Sí. La URL del iframe incluye la versión. Cambios no compatibles se lanzan en nuevas versiones, manteniendo las anteriores por un período de transición.

¿Cuánto tiempo de soporte tienen las versiones antiguas?​

Mínimo 6 meses desde el anuncio de deprecación. Te notificaremos con anticipación para que puedas migrar.

¿No encontraste tu respuesta?​

Contactanos:

  • Email: soporte@lakaut.com
  • Documentación: docs.lakaut.com
