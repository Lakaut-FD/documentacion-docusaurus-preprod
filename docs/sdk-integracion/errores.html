Errores y recuperación

lakaut.flow.failed expone únicamente información segura:

{
  type: "lakaut.flow.failed";
  errorCode: string;
  safeMessage?: string;
  retryable: boolean;
}

No muestres errores internos del backend directamente al usuario.

Qué debe conservarse en un reintento​

Para una clave incorrecta o un error temporal de firma:

  • conservar sesión;
  • conservar documento;
  • conservar paso actual;
  • borrar solamente el PIN;
  • impedir doble envío mientras la solicitud está en curso.

No obligues al usuario a repetir OTP, identidad o certificado.

Respuestas HTTP del backend​

EstadoInterpretación general
400 / 422Entrada o estado inválido
401Credencial inválida o vencida
403Integrador inválido o el origen no coincide con el vínculo de la sesión
404Sesión o recurso inexistente
409Conflicto con el estado actual
429Límite temporal; respetar espera/reintento
500 / 502 / 503 / 504Falla temporal de servicio o proveedor

Usá el código estable del error cuando esté disponible. Conservá correlationId para soporte, pero no agregues credenciales ni datos personales al ticket.
